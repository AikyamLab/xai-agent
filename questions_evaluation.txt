## Q1. Which part of the input was most responsible for the model’s prediction?

### Expected Outputs from Explanation
```json
{
  "vision": {
    "bounding_box": [x_min, y_min, x_max, y_max]
  },
  "text": {
    "start_index": int,
    "end_index": int
  },
  "tabular": {
    "feature_key": "string"
  }
}
Steps by Agent
Identify the most responsible part of the input.

Evaluation
Mask the identified part.

Run prediction on original and masked inputs.

Compare probability difference of the original top-1 class.

Metric
P_original - P_modified

Q3. Which specific parts distinguish the prediction from the next-best alternative?
Expected Outputs from Explanation
```json

  },

  },

  }
}

Steps by Agent
Identify the most decisive and unique part distinguishing top-1 and top-2 predictions.

Evaluation
Mask the identified parts.

Compare prediction probabilitie on the modified input of original top-1 and top-2 classes, see if the prediction rank of the two classes changes.

Q4. Why are instances A and B given different predictions?
Expected Outputs from Explanation
```json
{
  "input_A": {
    "vision": { "bounding_box": [x_min, y_min, x_max, y_max] },
    "text": { "start_index": int, "end_index": int },
    "tabular": { "feature_key": "string" }
  },
  "input_B": {
    "vision": { "bounding_box": [x_min, y_min, x_max, y_max] },
    "text": { "start_index": int, "end_index": int },
    "tabular": { "feature_key": "string" }
  }
}

Steps by Agent
Identify parts decisive for A and B that distinguish their predictions.

Evaluation
Mask both sets of parts in both inputs.

Run predictions before and after masking.

Compute probabilities for A’s original top-1 class on both inputs.

Metric
if (P_A_a1_original - P_B_a1_original) - (P_A_a1_modified - P_B_a1_modified) > 0 then 1 else 0

}

Compare resulting top-1 class with agent’s Yes/No judgment.

Metric

Q6. How should the instance change to flip the model prediction to [expected_class]?
Expected Outputs from Explanation
```json
{
  "vision": {
    "change_plan": {
      "bounding_box": [x_min, y_min, x_max, y_max],
      "action": "change | delete | swap | ...",
      "new_value": "optional"
    }
  },
  "text": {
    "change_plan": {
      "start_index": int,
      "end_index": int,
      "action": "change | delete | swap | ...",
      "new_value": "optional"
    }
  },
  "tabular": {
    "change_plan": {
      "feature_key": "string",
      "action": "change | delete | swap | ...",
      "new_value": "optional"
    }
  }
}

Steps by Agent
Propose an exact change plan to flip the prediction.

Evaluation
Apply the change plan to generate a modified instance (Note here we first try build functions to do the change, for example, for text/tabular data, we can do change/delete of specific region, but for vision, we need to input the change plan as prompt to the agent to generate the modified instance).

Run prediction on the modified instance.

Metric
if R1_modified == expected_class then 1 else 0

    "text": { "start_index": int, "end_index": int },

  },
  ...
}

Evaluation
Remove the shared feature from each input.

Run prediction on all modified inputs.

Metric
if ∀i (P_i_correct_modified - P_i_correct_original) > 0 then 1 else 0


Q10. Why are two similar instances given different predictions (one correct, one wrong)?
Expected Outputs from Explanation
```json
{
  "vision": "natural_language_description_of_shared_features",
  "text": {
    "start_index": int,
    "end_index": int
  },
  "tabular": {
    "feature_key": "string"
  }
}

Steps by Agent
Identify features leading to the correct prediction.

Identify features leading to the wrong prediction.

Evaluation
Compare feature sets from correct vs wrong predictions. Here, larger overlap means worse result

Metric
- Sim(F_correct, F_wrong)
Vision: word similarity on natural language descriptions

Text: word similarity

Tabular: rank correlation
